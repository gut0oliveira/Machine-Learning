## Sobre o repositório

Este repositório reúne projetos desenvolvidos para aplicar diferentes etapas de um pipeline de **Machine Learning**, desde a preparação e transformação dos dados até o treinamento, avaliação e comparação de modelos.

Os projetos exploram algoritmos de aprendizado supervisionado e diferentes métricas de avaliação para analisar o desempenho dos modelos em problemas preditivos.

## Tecnologias

- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Jupyter Notebook**

## Projetos

### Previsão de Chuva com Machine Learning

Projeto desenvolvido a partir de dados meteorológicos da Austrália, com o objetivo de utilizar características climáticas para prever a ocorrência de chuva no dia seguinte (`RainTomorrow`).

O projeto percorre diferentes etapas do processo de Machine Learning, incluindo preparação dos dados, transformação de variáveis categóricas, separação entre dados de treinamento e teste, treinamento de modelos e avaliação de desempenho.

### Modelos utilizados

#### Classificação

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Support Vector Machine (SVM)

#### Regressão

- Linear Regression

### Métricas de avaliação

Para os modelos de classificação:

- Accuracy
- Jaccard Index
- F1-Score
- Log Loss

Para o modelo de regressão:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

### Etapas do projeto

- Importação e exploração dos dados
- Pré-processamento
- Tratamento de variáveis categóricas
- One-Hot Encoding
- Separação dos dados em treino e teste
- Treinamento de diferentes algoritmos
- Avaliação e comparação dos modelos

**Tecnologias:** `Python` `Pandas` `NumPy` `Scikit-learn` `Jupyter Notebook`
